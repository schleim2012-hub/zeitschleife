# Giß-Moe – Credits & Lizenzen

- **3D-Modell, Fell-Shader, Augen, Animationen:** selbst erstellt für dieses Projekt (schleim2012-hub).
- **Kleiderschrank** (Zylinder, Krone, Partyhut, Mütze, Zauberhut, Schleife, Brillen, Fliege, Schal, Glöckchen), **Vampir-Umhang, Zähne, Milchbart, Eiszapfen, Becher fürs Hütchenspiel:** selbst modelliert in three.js-Code, keine fremden Assets.
- **Wimmelbild „Such Moe“:** prozedural erzeugt (Hintergrund im Code gemalt, Doppelgänger aus Live-Bild von Moe mit Farbverschiebung). Deko sind System-Emojis des Geräts.
- **Stimme (gelernte Wörter, Antworten von „Frag Moe“, Essens-Sprüche):** erzeugt mit ElevenLabs Text-to-Speech, Stimme „ZS kitty (Navi)“, Modell eleven_multilingual_v2, nachbearbeitet (Tonhöhe, Lautstärke). Nutzung gemäß ElevenLabs-Nutzungsbedingungen des Projekt-Kontos.
- **Geräusche** (Rattern, Fiepen, Glockenspiel, Schmatzen, Pupsen, Schluckauf …): live per WebAudio synthetisiert, keine Samples.
- **Sprachausgabe-Reserve:** Browser-Sprachsynthese (speechSynthesis) des Geräts, nur falls eine Aufnahme fehlt.
- **Schrift Kalam:** Indian Type Foundry, SIL Open Font License 1.1.
- **A-Frame 1.7.1 / three.js:** MIT-Lizenz.
