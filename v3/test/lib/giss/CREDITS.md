# Giß-Moe – Credits & Lizenzen

- **3D-Modell, Fell-Shader, Augen, Animationen:** selbst erstellt für dieses Projekt (schleim2012-hub).
- **Kleiderschrank** (Zylinder, Krone, Partyhut, Mütze, Zauberhut, Schleife, Brillen, Fliege, Schal, Glöckchen), **Vampir-Umhang, Zähne, Milchbart, Eiszapfen, Becher fürs Hütchenspiel:** selbst modelliert in three.js-Code, keine fremden Assets.
- **Wimmelbild „Such Moe“:** prozedural erzeugt (Hintergrund im Code gemalt, Doppelgänger aus Live-Bild von Moe mit Farbverschiebung). Deko sind System-Emojis des Geräts.
- **Stimme (ab v3):** ElevenLabs Text-to-Speech, Stimme „Lumi“ (Voice-ID zndmYEEoWWxRYyEL2ZZY, aus der ElevenLabs-Stimmbibliothek), Modell eleven_multilingual_v2, Sprechtempo 1,12, nachbearbeitet (Stille gekürzt, Lautstärke normalisiert). Alle Texte selbst geschrieben. Nutzung gemäß ElevenLabs-Nutzungsbedingungen des Projekt-Kontos. (v2 nutzte „ZS kitty (Navi)“.)
- **Frisuren, Kleidung (Freischalt-Sachen), Kamm/Schere/Farbe, Spiele Maulwurf und Giß-UNO (Karten, Regeln, Grafik):** eigener Code, Karten und Löcher per CSS/Canvas gezeichnet, Maulwurf-Figuren sind Live-Bilder von Moe bzw. System-Emojis. UNO-Regeln als bekannte Spielidee nachgebaut, kein Original-Logo, keine fremde Grafik.
- **Spracherkennung (Quatschen, App):** Android-SpeechRecognizer des Geräts (offline bevorzugt); im Browser Web Speech API. Keine Aufnahmen werden gespeichert.
- **Geräusche** (Rattern, Fiepen, Glockenspiel, Schmatzen, Pupsen, Schluckauf …): live per WebAudio synthetisiert, keine Samples.
- **Sprachausgabe-Reserve:** Browser-Sprachsynthese (speechSynthesis) des Geräts, nur falls eine Aufnahme fehlt.
- **Schrift Kalam:** Indian Type Foundry, SIL Open Font License 1.1.
- **A-Frame 1.7.1 / three.js:** MIT-Lizenz.
- **Halloween-Kostüme** (Gespensterlaken, Kürbis, Zombie, Skelett, Hexe, Frankensteinchen, Alien, Lottergeist, Meerjungfrau) und **neue Augen** (Iris-Shader, Glanzlichter, Blinzeln): eigener three.js-Code und Canvas-Texturen. „Lottergeist“ ist nur vom Stil gestreifter Gruselkomödien-Geister inspiriert, kein Markenname, keine fremden Figuren oder Grafiken.
